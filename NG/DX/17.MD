> Funkcionální programování, čisté funkce, funkce jako hodnota 1. třídy. Náhrada cyklu rekurzí.

Paradigma programování je základní přístup/filosofie při vytváření programu. Předurčuje pohled programátora na řešený problém, dostupné konstrukce konkrétních programovacích jazyků apod. Pro tato paradigmata neexistuje žádná oficiální specifikace. S celkovým vývojem přicházela paradigmata zaměřena na řešení větších projektů ve větších týmech a s vyšší abstrakcí.

## Funkcionální programování

Funkcionální programování je paradigma, kde je výpočet vyhodnocením funkcí. Funkce jsou inspirované těmi matematickými, a definují tedy vztah mezi vstupními a výstupními hodnotami. Celý program je sada spolupracujících funkcí. Vyhýbá se stavovým datům (proměnným, potenciální riziko) – průběžné hodnoty se předávají ve výsledcích a parametrech funkcí. Často se využívá rekurze a funkcí vyššího řádu (funkce přijímající a/nebo vracející jiné funkce), proměnné jsou obvykle _immutable_ (nelze měnit jejich hodnotu). Mezi představitele tohoto paradigmatu patří Lisp, Scheme, Racket, Haskell, F# a další.

### Čisté funkce

Čisté funkce musí splňovat dvě pravidla:

* Nemají žádné vedlejší efekty. Nemodifikují globální proměnné, nezapisují do souboru, nekomunikují po síti atd.

* Jejich výsledek závisí vždy pouze na vstupních parametrech. Pro dané vstupní parametry vždy vrací stejný výsledek.

### Funkce jako hodnota 1. třídy

Pokud programovací jazyk splňuje tuto vlastnost, pak lze s funkcemi zacházet jako s jakoukoliv jinou hodnotou. Tedy přiřadit je do proměnné, předat je jako parametr, vrátit je jako výsledek funkce apod.

V jazyce s touto vlastností proto lze definovat funkce vyššího řádu (_higher-order functions_), což jsou funkce, které splňují alespoň jedno z: příjímá funkci jako parametr, vrací funkci jako výsledek.

### Náhrada cyklu rekurzí

Při zpracování kolekcí se namísto cyklu využívá těchto prvků: _hlava_, _ocas_, _podmíněný výraz_ a _rekurze_. Hlava je funkce vracející první prvek daného seznamu, ocas vrací zbytek tohoto seznamu (vše krom prvního prvku).

```scheme
(define muj-seznam (list 1 2 3 4))

; (car seznam) je funkce typu hlava:
(car muj-seznam)  ; vrací 1

; (cdr seznam) je funkce typu ocas:
(cdr muj-seznam)  ; vrací (list 2 3 4)

; Funkce lze řetězit:
(car (cdr muj-seznam))        ; vrací 2
(car (cdr (cdr muj-seznam)))  ; vrací 3, hodil by se ale lepší způsob

; Využijeme podmíněného výrazu a rekurze:
(define (get seznam index)
  (cond
    [(empty? seznam) #f]
    [(= index 0) (car seznam)]
    [else (get (cdr seznam) (- index 1))]))

(get muj-seznam 2)  ; vrací 3
```

Máme k dispozici přístup jen k prvnímu prvku a celému zbytku seznamu. Postup je tedy takový, že funkce zpracuje hlavu vstupního seznamu, následně zavolá sama sebe a předá si ocas. Samotné zpracování obvykle obsahuje nějaké rozvětvení – funkce `cond` postupně vyhodnocuje podmínky a použije první úspěšnou.

Rekurzivnímu volání by měly předcházet ukončovací podmínky. Jelikož si předáváme ocas seznamu, tak nám prvky jednou dojdou – vhodná chvíle přestat s rekurzí. Proto první kontrola řeší, zdali je seznam prázdný. Pokud se náš původně chtěný index dostal na nulu, tak jsme „dokrokovali“ na chtěný prvek seznamu a můžeme ho vrátit, jinak rekurzivně voláme sebe sama s ocasem a indexem menším o jedničku.

Podobným stylem řešíme všechny problémy.

#### Hledání hodnoty v seznamu (_exists_)

* Dostali jsme prázdné pole? ⇒ Hodnota nenalezena.
* Je hledaná hodnota rovna hlavě? ⇒ Hodnota nalezena.
* Jinak volej sebe sama na ocas.

Vždy nejprve testujeme cílové situace (prázdný seznam, hodnota nalezena, ...). Následuje výraz určující výsledek, který obsahuje rekurzivní volání pro zjednodušenou úlohu (např. pro zbytek seznamu).

#### Suma hodnot v seznamu

```csharp
// Suma0: „Klasický“ nefunkcionální přístup.
public int Suma0(int[] seznam)
{
    int vysledek = 0;
    foreach (int item in seznam) vysledek += item;
    return vysledek;
}

// Suma1: Funkcionální, kde se výsledek postupně tvoří v parametru funkce.
//        Do parametru je na začátku nutné dosadit počáteční hodnotu (v tomto případě 0),
//        proto se často obaluje do další funkce, která jej dosadí.
private int Suma1Impl(int[] seznam, int vysledek)
{
    if (IsEmpty(seznam)) return vysledek;
    else return Suma1Impl(Ocas(seznam), vysledek + Hlava(seznam));
}

public int Suma1(int[] seznam) => Suma1Impl(seznam, 0);

// Suma2: Funkcionální, kde se výraz postupně tvoří při návratech z rekurzivního volání.
public int Suma2(int[] seznam)
{
    if (IsEmpty(seznam)) return 0;
    else return Hlava(seznam) + Suma2(Ocas(seznam));
}
```

Přístup `Suma1` nazýváme _určení hodnoty __shora dolů___. Výsledek se tvoří v parametru a na konci rekurze ho jen stačí vrátit. Může být rychlejší, ale pro někoho míň přirozené a vyžaduje parametr navíc (nebo obalující funkci).

Přístup `Suma2` nazýváme _určení hodnoty __zdola nahoru___. Na konci rekurze se postupně vracíme a tvoříme výsledek.

Pro pořádek ještě ve Scheme:

```scheme
;; Suma1
(define (suma1_impl seznam vysledek)
  (cond
    [(empty? seznam) vysledek]
    [else (suma1_impl (cdr seznam) (+ vysledek (car seznam)))]))

(define (suma1 seznam) (suma1_impl seznam 0))

;; Suma2
(define (suma2 seznam)
  (cond
    [(empty? seznam) 0]
    [else (+ (car seznam) (suma2 (cdr seznam)))]))
```

#### Obecné hledání

```scheme
(define (hledej? kriterium? CO KDE)
  (cond
    [(empty? KDE) #f]
    [(kriterium? CO (car KDE)) #t]
    [else (hledej? kriterium? CO (cdr KDE))]))
```

Funkce hledá prvek v seznamu, který se podle určitého kritéria shoduje se zadaným prvkem. Kritérium určujeme až při volání dosazením konkrétní funkce.

```scheme
(hledej? = 10 (list 5 10 15))  ; vrací #t (dosadili jsme funkci `=`)

(define (delitel? A B) (= (remainder A B) 0))

(hledej? delitel? 7 (list 2 3 4 5 6))  ; vrací #f
```

V prvním příkladě dosazujeme `=` a `10`, hledáme tedy číslo rovné desíti. V druhém příkladě dosazujeme `delitel?` a `7`, hledáme tedy dělitele sedmičky (prohozením `A` a `B` bychom hledali číslo dělitelné sedmi).

#### Obecné filtrování seznamu

```scheme
(define (filtr podminka? seznam)
  (cond
    [(empty? seznam) (list)]
    [(podminka? (car seznam)) (cons (car seznam) (filtr podminka? (cdr seznam)))]
    [else (filtr podminka? (cdr seznam))]))
```

Funkce `(cons x L)` přidá prvek `x` na začátek seznamu `L`, tedy např. `(cons 0 (list 1 2 3 4))` vrací `(list 0 1 2 3 4)`. Na konci rekurze vracíme prázdný seznam a jak se postupně vracíme, přidáváme na jeho začátek vyhovující prvky.

```scheme
(filtr positive? (list -1 1 -2 2 -3 3))  ; vrací (list 1 2 3)

(filtr even? (list -1 1 -2 2 -3 3))  ; vrací (list -2 2)
```
