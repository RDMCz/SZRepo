> Základy teorie dělitelnosti, základní pojmy (relace býti dělitelem a její vlastnosti, věta o dělení se zbytkem), eukleidův algoritmus, využití. Řetězové zlomky (konstrukce, vlastnosti), řešení kongruencí 1. stupně a jejich soustav.

## Teorie dělitelnosti

* Celá čísla jsou uzavřená vzhledem k operaci sčítání, odčítání a násobení
  * ⇒ Součet, rozdíl i součin celých čísel je opět celé číslo
* Teorie dělitelnosti zkoumá vlastnosti celých čísel vůči operaci dělení

### Dělitelnost

* Řekneme, že nenulové celé číslo 𝑏 dělí celé číslo 𝑎, jestliže __∃ 𝑞 ∈ ℤ takové, že 𝑎 = 𝑏 ∙ 𝑞__
* Píšeme 𝑏|𝑎
* Každé číslo 𝑎 má nevlastní dělitele ±1 a ±𝑎; ostatní případní dělitelé jsou vlastní

### Vlastnosti dělitelnosti

\#|Pro|Platí|Poznámka
---|---|---|---
1.|∀𝑎 ∈ ℤ|1\|𝑎|<small>_Jedna dělí vše_</small>
2.|∀𝑎 ∈ ℤ∖{0}|𝑎\|0|<small>_Vše krom nuly dělí nulu_</small>
3.|∀𝑎 ∈ ℤ∖{0}|𝑎\|𝑎|Reflexivita, <small>_vše krom nuly dělí sebe sama_</small>
4.|∀𝑎,𝑏 ∈ ℤ|(𝑏\|𝑎) ∧ (𝑎\|𝑏) ⇒ (𝑎 = 𝑏) ∨ (𝑎 = -𝑏)|Pro ℕ⁺ ⇒ (𝑎 = 𝑏), tedy antisymetrie
↳|∀𝑎,𝑏 ∈ ℤ∖{0}|𝑏\|𝑎 ⇒ ±𝑏\|±𝑎|Bez újmy se lze omezit pouze na kladné dělitele
5.|∀𝑎,𝑏,𝑐 ∈ ℤ|(𝑐\|𝑏) ∧ (𝑏\|𝑎) ⇒ 𝑐\|𝑎|Tranzitivita
6.|∀𝑎,𝑏,𝑐 ∈ ℤ|𝑏\|𝑎 ⇒ 𝑏\|𝑎𝑐|<small>_Když_ 𝑏 _dělí_ 𝑎, _tak dělí i jeho libovolný násobek_</small>
7.|∀𝑎,𝑏,𝑐 ∈ ℤ|(𝑎 + 𝑏 = 𝑐) ∧ (𝑑\|𝑎) ∧ (𝑑\|𝑐) ⇒ 𝑑\|𝑏|(𝑐 > 𝑎) ∧ (𝑑\|𝑎) ∧ (𝑑\|𝑐) ⇒ 𝑑\|(𝑐-𝑎)

* Co je tedy „relace býti dělitelem“?
  * Binární relace na množině 𝐴 je libovolná podmnožina 𝐴²
  * Např. relace rovnost „=“ obsahuje všechny dvojice (𝑎, 𝑎) ∈ 𝐴²
  * Relace dělitelnosti tedy obsahuje všechny dvojice (𝑎, 𝑏), kde platí, že 𝑎|𝑏

### Dělení se zbytkem

Pro libovolné 𝑎 ∈ ℤ, 𝑏 ∈ ℕ⁺ existují __jediná__ čísla 𝑞, 𝑟 ∈ ℤ taková, že 𝑎 = 𝑏𝑞 + 𝑟, kde __0 ≤ 𝑟 < 𝑏__.

* 𝑎 je dělenec
* 𝑏 je dělitel
* 𝑞 je neúplný podíl
* 𝑟 je zbytek
* 𝑟 = 𝑎 - 𝑏𝑞
* Využití mj. při převodu z desítkové do jiné číselné soustavy

### Společný dělitel

* 𝑑|𝑎 ∧ 𝑑|𝑏 ⇔ 𝑑 je společný dělitel čísel 𝑎 a 𝑏
  * 𝑎,𝑏 ∈ ℤ
  * 𝑑 ∈ ℕ⁺ (s touto definicí vyšetřujeme pouze kladné dělitele (bez újmy na obecnosti))
* 𝑑<sub>𝑎,𝑏</sub> = {𝑑 ∈ ℕ⁺ ⁞ (𝑑|𝑎) ∧ (𝑑|𝑏)} je množina všech společných dělitelů 𝑎 a 𝑏
  * Je neprázdná a shora omezená
  * 1 ≤ 𝑑 ≤ min{|𝑎|, |𝑏|}
  * Množina má tedy největší prvek ⇒ největší společný dělitel

### NSD – největší společný dělitel

* NSD(𝑎,𝑏) je takový společný dělitel čísel 𝑎 a 𝑏, který je ze všech největší
* Alespoň jedno číslo musí být nenulové: NSD(0,0) nelze
* NSD existuje vždy a je určen jednoznačně
* Pokud NSD(𝑎,𝑏) = 1, pak jsou tato čísla _nesoudělná_
* Metody výpočtu NSD:
  1. Bruteforce
  2. Využití prvočíselných rozkladů
  3. Eukleidův algoritmus – opakované využití věty o dělení se zbytkem
  4. Dvojkový NSD algoritmus

### Vlastnosti NSD

\#|Platí|Poznámka
---|---|---
1.|NSD(𝑎,𝑎) = 𝑎|&nbsp;
2.|Pokud 𝑎 ≠ 0, pak NSD(𝑎,0) = 𝑎|&nbsp;
3.|NSD(𝑎,𝑏) = NSD(𝑏,𝑎)|Symetrie
4.|NSD(𝑎,𝑏) = NSD(±𝑎,±𝑏)|Při hledání NSD se lze omezit na obor ℕ⁺
5.|𝑑\|𝑎 ∧ 𝑑\|𝑏 ⇔ 𝑑\|NSD(𝑎,𝑏)|Libovolný společný dělitel dělí NSD
6.|NSD(𝑘𝑎, 𝑘𝑏) = 𝑘 ⋅ NSD(𝑎,𝑏)|Společný dělitel 𝑘 čísel 𝑘𝑎 a 𝑘𝑏 lze vytknout
7.|NSD(𝑎,𝑏) = 1 ⇒ NSD(𝑎𝑐,𝑏) = NSD(𝑐,𝑏)|Obecně: u NSD(𝑥,𝑦) můžeme 𝑥 vydělit číslem nesoudělným s 𝑦

### Eukleidův algoritmus

𝑎 = 𝑏 ⋅ 𝑞₀ + 𝑟₁ &emsp;&nbsp;&nbsp; 0 „≤“ 𝑟₁ < 𝑏 <br>
𝑏 = 𝑟₁ ⋅ 𝑞₁ + 𝑟₂ &emsp;&nbsp; 0 „≤“ 𝑟₂ < 𝑟₁ <br>
𝑟₁ = 𝑟₂ ⋅ 𝑞₂ + 𝑟₃ &emsp; 0 „≤“ 𝑟₃ < 𝑟₂ <br>
...<br>
𝑟<sub>𝑛-1</sub> = __𝑟<sub>𝑛</sub>__ ⋅ 𝑞<sub>𝑛</sub>

* Postupná aplikace věty o dělení se zbytkem
* Po konečném počtu aplikací se zbytek dostane k nule
* NSD(𝑎,𝑏) je rovno poslednímu nenulovému zbytku v Eukleidově algoritmu aplikovaném na 𝑎,𝑏
* NSD(𝑎,𝑏) = NSD(𝑏,𝑟₁)= NSD(𝑟₁,𝑟₂) = ... = NSD(𝑟<sub>𝑛</sub>,0)
* Počet kroků je nejvýše roven pětinásobku počtu cifer menšího z čísel 𝑎,𝑏

### Funkce dolní celá / horní celá / lomená část

```text
dolní celá část     ⌊ ⌋     ℝ → ℤ     ∀𝑥 ∈ ℝ     ⌊𝑥⌋ ≤ 𝑥 < ⌊𝑥⌋ + 1     (největší celé číslo ≤ 𝑥, "floor")

horní celá část     ⌈ ⌉     ℝ → ℤ     ∀𝑥 ∈ ℝ     ⌈𝑥⌉ ≥ 𝑥 > ⌈𝑥⌉ - 1     (nejmenší celé číslo ≥ 𝑥, "ceil")

    lomená část     { }     ℝ → ℝ   H𝑓 ∈ <0, 1)   {𝑥} = 𝑥 - ⌊𝑥⌋
```

### Řetězové zlomky

Při numerických výpočtech vždy pracujeme s jistou konečnou podmnožinou ℚ (např. nikdy nepočítáme s přesným π, nelze). Problematika diofantické aproximace zkoumá, jak přesně lze čísla aproximovat pomocí racionálních čísel určitých vlastností. Každé číslo _α_ ∈ ℝ ∖ ℤ lze vyjádřit jediným způsobem ve tvaru:

_α_ = 𝑞₀ + 1/<i>α</i>₁

kde 𝑞₀ ∈ ℤ, <i>α</i>₁ > 1, 𝑞₀ = ⌊_α_⌋, 1/<i>α</i>₁ = {_α_}. Pokud <i>α</i>₁ není přirozené číslo, lze postupovat analogicky:

<i>α</i>₁ = 𝑞₁ + 1/<i>α</i>₂

kde 𝑞₁ ∈ ℕ⁺, <i>α</i>₂ > 1, 𝑞₁ = ⌊<i>α</i>₁⌋, 1/<i>α</i>₂ = {<i>α</i>₁}. Odtud:

![$$α=q_0+\frac{1}{q_1+\frac{1}{α_2}}$$](./MG/LX/01-56c1947336.svg)

Tento postup lze opakovat, dokud v některém kroku nedostaneme _α_<sub>𝑛</sub> ∈ ℕ⁺ (to může nastat hned v prvním kroku, nebo také nikdy). Řetězovým zlomkem tedy nazveme ne/konečný výraz ve tvaru:

![$$q_0+\cfrac{1}{q_1+\cfrac{1}{q_2+\cfrac{1}{q_3+\cfrac{1}{\ddots}}}}$$](./MG/LX/01-cf70d8d4cf.svg)

* Výraz je konečný, pokud ∃ 𝑛 ∈ ℕ⁺ takové že _α_<sub>𝑛</sub> ∈ ℕ⁺
* Výraz je nekonečný, pokud ∀𝑛 platí _α_<sub>𝑛</sub> ∈ ℝ ∖ ℕ
* Reálné číslo má konečný rozvoj v řetězový zlomek právě tehdy, je-li racionální
* 𝑞<sub>𝑖</sub> nazýváme členy rozvoje v řetězový zlomek
* Při „tvorbě“ výrazu nám postupně vznikají <i>δ</i>₀ = 𝑞₀, <i>δ</i>₁ = 𝑞₀ + 1/𝑞₁, ...
  * Nazýváme přibližné (částečné) zlomky
  * Obvykle zkracujeme zápis: <i>δ</i>₀ = \[𝑞₀\], <i>δ</i>₁ = [𝑞₀, 𝑞₁], ..., _δ_<sub>𝑛</sub> = [𝑞₀, 𝑞₁, ..., 𝑞<sub>𝑛</sub>]
  * Obecně _δ_<sub>𝑖</sub> = 𝑃<sub>𝑖</sub>/𝑄<sub>𝑖</sub>, čitatel 𝑃<sub>𝑖</sub> a jmenovatel 𝑄<sub>𝑖</sub> jsou definovány rekurentním vztahem
    * 𝑃<sub>𝑖</sub> = 𝑞<sub>𝑖</sub> ⋅ 𝑃<sub>𝑖-1</sub> + 𝑃<sub>𝑖-2</sub> &emsp; kde 𝑃<sub>-1</sub> = 1 a 𝑃₀ = 𝑞₀  &emsp; případně 𝑃<sub>-2</sub> = 0 a 𝑃<sub>-1</sub> = 1
    * 𝑄<sub>𝑖</sub> = 𝑞<sub>𝑖</sub> ⋅ 𝑄<sub>𝑖-1</sub> + 𝑄<sub>𝑖-2</sub> &emsp; kde 𝑄<sub>-1</sub> = 0 a 𝑄₀ = 1 &emsp; případně 𝑄<sub>-2</sub> = 1 a 𝑄<sub>-1</sub> = 0
  * Přibližné zlomky jsou v základním (zkráceném/redukovaném) tvaru, tedy NSD(𝑃<sub>𝑖</sub>, 𝑄<sub>𝑖</sub>) = 1
  * Přibližné zlomky jsou nejlepší aproximace reálných čísel pomocí racionálních čísel, jejichž jmenovatel je nejvýše roven 𝑄<sub>𝑖</sub>

### Kongruence

Řekneme, že celá čísla 𝑎,𝑏 jsou kongruentní modulo 𝑚 ∈ ℕ⁺, jestliže obě čísla mají při dělení modulem 𝑚 stejný zbytek. Píšeme 𝑎 ≡ 𝑏 (𝑚). Znamená to, že 𝑎,𝑏 se liší o násobek čísla 𝑚. Využití např. při generování pseudonáhodných čísel.

#### Následující tvrzení jsou ekvivalentní

1. 𝑎 ≡ 𝑏 (𝑚)
2. 𝑚|(𝑎 - 𝑏)
3. 𝑎 = 𝑏 + 𝑚𝑡 &emsp; 𝑡 ∈ ℤ

#### Pro relaci „býti kongruentní modulo 𝑚“ platí (𝑚 ∈ ℕ⁺ a ∀𝑎,𝑏,𝑐 ∈ ℤ)

1. 𝑎 ≡ 𝑎 (𝑚) &emsp; reflexivita
2. 𝑎 ≡ 𝑏 (𝑚) ⇔ 𝑏 ≡ 𝑎 (𝑚) &emsp; symetrie
3. 𝑎 ≡ 𝑏 (𝑚) ∧ 𝑏 ≡ 𝑐 (𝑚) ⇒ 𝑎 ≡ 𝑐 (𝑚) &emsp; tranzitivita

* Ekvivalence je taková relace, která je reflexivní, symetrická a tranzitivní
* Proto relaci se symbolem „≡“ nazýváme ekvivalencí na ℤ
* Tato relace definuje rozklad ℤ na 𝑚 tříd ekvivalence
  * [0], [1], ..., [𝑚-1] = {𝑡𝑚}, {𝑡𝑚 + 1}, ..., {𝑡𝑚 + (𝑚-1)} ⁞ 𝑡 ∈ ℤ

#### Úplná soustava zbytků modulo 𝑚

* Značíme ℤ<sub>𝑚</sub>
* Z každé zbytkové třídy vybereme právě jednoho reprezentanta
* Nejčastěji pracujeme s úplnou soustavou nejmenších nezáporných zbytků {0, 1, ..., 𝑚-1}

#### Operace na ℤ<sub>𝑚</sub>

* Sčítání modulo 𝑚
  * Asociativní, komutativní, existence nulového a opačného prvku
  * Např. na ℤ₆ je pro prvek 5 opačný prvek 1 (protože -5 ≡ 1)
  * (Sečtení s _opačným_ prvkem dá nulu)
* Násobení modulo 𝑚
  * Asociativní, komutativní, existence neutrálního prvku
  * Prvek 𝑎 ∈ ℤ<sub>𝑚</sub> má inverzní prvek právě tehdy, jestliže NSD(𝑎,𝑚) = 1
  * (Vynásobení s _inverzním_ prvkem dá jedničku)

#### Řešení kongruencí a jejich soustav

* Pod pojmem kongruence rozumíme výraz 𝑓(𝑥) ≡ 0 (𝑚)
  * 𝑚 ∈ ℕ ∖ {0,1} je modul
  * 𝑓(𝑥) = 𝑎<sub>𝑛</sub>𝑥<sup>𝑛</sup> + ... + 𝑎₁𝑥 + 𝑎₀ je nenulový polynom s koeficienty ze ℤ<sub>𝑚</sub>
    * 𝑚∤𝑎<sub>𝑛</sub> &emsp; (násobek 𝑚 je kongruentní s nulou, nesplnění by snížilo stupeň polynomu)
    * 𝑛 nazýváme stupněm kongruence
* __Řešit kongruenci znamená nalézt všechna celá 𝑥 ∈ ℤ, která jí vyhovují__
* __𝑓(𝑥₀) ≡ 0 (𝑚) &ensp;⇒&ensp; ∀𝑡 ∈ ℤ&ensp; 𝑓(𝑥₀ + 𝑚𝑡) ≡ 0 (𝑚)__
  * Pokud kongruenci vyhovuje 𝑥₀, vyhovují jí pak všechna 𝑥 kde 𝑥 ≡ 𝑥₀ (𝑚)
  * Za jedno řešení považujeme celou zbytkovou třídu {𝑥₀ + 𝑚𝑡 ⁞ 𝑡 ∈ ℤ}
  * __Kongruenci vyhovuje buď 0, nebo ∞ čísel__
  * __Kongruence má nejvýše 𝑚 řešení__
  * Lze nalézt hrubou silou dosazováním čísel 0, 1, ..., 𝑚-1

#### Kongruence 1. stupně

* 𝑎𝑥 ≡ 𝑏 (𝑚)
* (Hledáme takové 𝑥, kterým když vynásobíme 𝑎, tak se bude lišit od 𝑏 o nějaký násobek 𝑚)
* Pokud NSD(𝑎,𝑚) = 1, pak má kongruence 𝑎𝑥 ≡ 𝑏 (𝑚) pro libovolné 𝑏 ∈ ℤ právě jedno řešení ve tvaru 𝑥₀ ≡ (-1)<sup>𝑛</sup> ⋅ 𝑃<sub>𝑛-1</sub> ⋅ 𝑏 (𝑚), kde 𝑃<sub>𝑛-1</sub> je čitatel předposledního přibližného zlomku rozvoje 𝑚/𝑎 v řetězový zlomek
* Pro kongruenci, kde NSD(𝑎,𝑚) = 𝑑, platí:
  1. 𝑑∤𝑏 ⇔ kongruence 𝑎𝑥 ≡ 𝑏 (𝑚) nemá řešení
  2. 𝑑|𝑏 ⇔ kongruence 𝑎𝑥 ≡ 𝑏 (𝑚) má 𝑑 řešení
  * (V řadě 0, ..., 𝑚-1 najdu 𝑑 řešení; vyhovujících čísel je nekonečno)

#### Soustavy kongruencí 1. stupně

##### Čínská věta o zbytku

Uvažujeme soustavu kongruencí tvaru 𝑥 ≡ 𝑏₁ (𝑚₁), ..., 𝑥 ≡ 𝑏<sub>𝑘</sub> (𝑚<sub>𝑘</sub>), kde ∀𝑖≠𝑗 NSD(𝑚<sub>𝑖</sub>,𝑚<sub>𝑗</sub>)=1 (moduly jsou po dvou nesoudělné). Tato soustava má pro libovolné pravé strany 𝑏₁, ..., 𝑏<sub>𝑘</sub> právě jedno řešení modulo 𝑀 = 𝑚₁ ⋅ ... ⋅ 𝑚<sub>𝑘</sub> (spadá do jedné zbytkové třídy). Toto řešení je tvaru:

𝑥 ≡ 𝑥₀ (mod 𝑀)<br>
𝑥₀ ≡ 𝑀₁<i>M̄</i>₁𝑏₁ + ... + 𝑀₁<sub>𝑘</sub>_M̄_<sub>𝑘</sub>𝑏<sub>𝑘</sub> (mod 𝑀)

kde ∀𝑖 &emsp; 𝑀<sub>𝑖</sub> = 𝑀/𝑚<sub>𝑖</sub> &ensp; ∧ &ensp; 𝑀<sub>𝑖</sub> ⋅ _M̄_<sub>𝑖</sub> ≡ 1 (𝑚<sub>𝑖</sub>)

_M̄_<sub>𝑖</sub> je prvek inverzní k 𝑀<sub>𝑖</sub> modulo (𝑚<sub>𝑖</sub>).

##### Zobecněná čínská věta o zbytku

Uvažujeme stejnou soustavu bez podmínky nesoudělnosti 𝑚<sub>𝑖</sub>. Nutnou a postačující podmínkou řešení je ∀𝑖≠𝑗 NSD(𝑚<sub>𝑖</sub>,𝑚<sub>𝑗</sub>)|(𝑏<sub>𝑖</sub> - 𝑏<sub>𝑗</sub>). Označíme-li navíc 𝑀 = NSN(𝑚₁, ..., 𝑚<sub>𝑘</sub>) a 𝑐<sub>𝑖</sub>, 𝑑<sub>𝑖</sub> pro 𝑖 = 1, ..., 𝑘 taková čísla, že:

1. 𝑑₁ ⋅ ... ⋅ 𝑑<sub>𝑘</sub> = 𝑀 &ensp; ∧ &ensp; ∀𝑖 𝑑<sub>𝑖</sub>|𝑚<sub>𝑖</sub> &ensp; ∧ &ensp; ∀𝑖≠𝑗 NSD(𝑑<sub>𝑖</sub>,𝑑<sub>𝑗</sub>) = 1
   * Déčka jsou po dvou nesoudělná, každé dělí svůj patřičný modul a jejich vynásobením dostaneme 𝑀

2. 𝑐<sub>𝑖</sub> ≡ 0 (𝑀/𝑑<sub>𝑖</sub>) &ensp; ∧ &ensp; 𝑐<sub>𝑖</sub> ≡ 1 (𝑑<sub>𝑖</sub>)
   * ⇒  (𝑀/𝑑<sub>𝑖</sub>)𝑡 ≡ 1 (𝑑<sub>𝑖</sub>) &ensp; ⇔ &ensp; 𝑐<sub>𝑖</sub> = (𝑀/𝑑<sub>𝑖</sub>)𝑡

Potom jediné řešení soustavy je tvaru: 𝑥 ≡ 𝑐₁ ⋅ 𝑏₁ + ... + 𝑐<sub>𝑘</sub> ⋅ 𝑏<sub>𝑘</sub> (mod 𝑀)

(NSN je nejmenší společný násobek – nejmenší číslo, které je dělitelné všemi vstupními čísly)
